# 中点算法画圆
​首先，我们考虑画圆心在 $(0,0)$ 的圆，其它情况仅需要平移即可。

根据圆的对称性，我们只需要画出第一象限的的圆弧，即可通过对称画出整个圆。

圆心在 $(0,0)$ ，半径为 $R$ 的圆对应的隐函数为：$F(x,y)=x^2+y^2−R^2=0$，代入各点，有：

1. 当 $F(x,y)=x^2+y^2−R^2=0$ 时，点在圆上；
2. 当 $F(x,y)=x^2+y^2−R^2>0$ 时，点在圆外；
3. 当 $F(x,y)=x^2+y^2−R^2<0$ 时，点在圆内。

考虑第一象限的 $\dfrac{1}{8}$ 圆弧，假设当前点在 $P_0(x,y)$ ，考虑下一个点选择 $B(x+1,y)$ 还是 $A(x+1,y−1)$。

![](/img/Pasted%20image%2020230913155338.png ':size=70%')

下一个点显然是选择 **离圆弧更近的点** ，我们可以通过判断点 $C(x+1,y−0.5)$ 在 **圆内** 还是 **圆外**，来判断 $(x+1,y)$ 、 $(x+1,y−1)$ 哪个离圆弧更近
（需要注意的是：如果 $(x+1,y−0.5)$ **恰好在圆上**，算法选择 $(x+1,y−1)$ 来作为下一个点，方便将1.25改为1，省去浮点运算）。

也就是说，对于 $(x,y)$ ，我们判断
$$
\begin{split}d &= F(x+1,y-0.5)\\ &= (x+1)^2+(y-0.5)^2-R^2\\ &= x^2+y^2+2x-y+1.25-R^2\end{split}​
$$
的值，来判断下一个点的选择情况。
1. 若 $d\lt 0$，选择 $(x+1,y)$ 作为下一个点。  
    此时，判断 $(x+1,y)$ 的下一个点的判断值为：
$$\begin{aligned} d' &= F((x+1)+1,(y)-0.5)\\ &= F(x+2,y-0.5)\\ &= (x+2)^2+(y-0.5)^2-R^2\\ &= x^2+y^2+4x-y+4.25-R^2\\ &= (x^2+y^2+2x-y+1.25-R^2)+2x+3\\ &= d+2x+3 \end{aligned}​$$
2. 若 $d \ge 0$，选择 $(x+1,y-1)$ 作为下一个点。  
    此时，判断 $(x+1,y−1)$ 的下一个点的判断值为：
$$\begin{aligned} d' &= F((x+1)+1,(y-1)-0.5)\\ &= F(x+2,y-1.5)\\ &= (x+2)^2+(y-1.5)^2-R^2\\ &= x^2+y^2+4x-3y+6.25-R^2\\ &= (x^2+y^2+2x-y+1.25-R^2)+2x-2y+5\\ &= d+2x-2y+5 \end{aligned}$$
这样我们就可以递推 $d$ 的值，不断选择点并更新判断值。

同时考虑初始点 $(0,R)$ ，显然有：

$$\begin{aligned} d_0 &= F(0+1,R-0.5)\\ &= 1+(R-0.5)^2-R^2\\ &= 1.25-R \end{aligned}$$

python代码实现如下：
```python
def MidPointCircle(r):  
    x1=0  
    y1=r  
    d=1-r # 原本是1.25-r,但由于下面判断时将d>0与d=0判为一类，改为1-r结果不变且省去浮点运算 
    plt.plot(x1,y1,'ro')  
    while x1 <= y1:  
        if d<0 :  
            d+=2*x1+3  
        else:  
            d += 2*(x1-y1)+5  
            y1 -= 1  
        x1 += 1  
        # 八对称性画圆
		plt.plot(x1,y1,'ro')   # 原八分之一圆弧
		plt.plot(x1,-y1,'ro')  # 关于x轴对称
		plt.plot(-x1,y1,'ro')  # 关于y轴对称
		plt.plot(-x1,-y1,'ro') # 关于原点对称
        plt.plot(y1,x1,'ro')   # 关于y=x对称
        plt.plot(y1,-x1,'ro')  # 关于y=x对称后再关于x轴对称
        plt.plot(-y1,x1,'ro')  # 关于y=x对称后再关于y轴对称
        plt.plot(-y1,-x1,'ro') # 关于y=x对称后再关于原点对称
    plt.show()
```
