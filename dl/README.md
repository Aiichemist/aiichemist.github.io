主要符号表

| 符号                                | 意义                                         |
| ---------------------------------- | ------------------------------------------- |
| $a$                                | 标量                                          |
| $\boldsymbol{a}$                   | 向量                                          |
| $A$                                | 矩阵                                          |
| $I$                                | 单位矩阵                                        |
| $\mathbb{R}$                       | 实数集                                         |
| $A^T$                              | 矩阵$A$的转置                                    |
| $A\odot B$                         | $A$和$B$的按元素乘积                               |
| $\dfrac{dy}{dx}$                   | $y$关于$x$的导数                                 |
| $\dfrac{\partial y}{\partial x}$   | $y$关于$x$的偏导数                                |
| $\nabla_x y$                       | $y$关于$x$的梯度                                 |
| $a\thicksim p$                     | 具有分布$p$的随机变量$a$                             |
| $\mathbb{E}[f(x)]$                 | $f(x)$的期望                                   |
| $Var(f(x))$                        | $f(x)$的方差                                   |
| $\exp(x)$                          | $x$ 的指数函数                                   |
| $\log x$                           | $x$ 的对数函数                                   |
| $\sigma(x)$                        | Sigmoid函数,$\sigma(x)=\dfrac{1}{1+\exp(-x)}$ |
| $s$                                | 状态                                          |
| $a$                                | 动作                                          |
| $r$                                | 奖励                                          |
| $\pi$                              | 策略                                          |
| $\gamma$                           | 折扣因子                                        |
| $G_t$                              | 时刻$t$时的回报                                   |
| $\mathop{\arg\min}\limits_{a}f(x)$ | $f(a)$取最小值时$a$的值                            |
