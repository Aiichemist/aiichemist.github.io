# 基于术语词典干预的机器翻译挑战赛
@ Datawhale AI夏令营

### 一、任务目标

1. 学会如何在魔搭平台上运行代码。
2. 在讯飞比赛官网提交合规的结果。
3. 理解机器翻译的发展历程。
4. 学习在机器学习和深度学习项目中如何划分数据集。

### 二、机器翻译的发展历程

1. **基于规则的机器翻译（1950s-1980s）**：
   - **特点**：利用语言学家编写的语法规则和词典进行翻译。
   - **优势**：对语法和词汇有深入的理解。
   - **劣势**：灵活性和适应性差，难以处理复杂的语言结构和多义词问题。

2. **基于统计的机器翻译（1990s-2000s）**：
   - **特点**：通过分析大量双语文本，自动学习源语言和目标语言之间的对应关系。
   - **优势**：处理多义词和语言变异方面效果较好。
   - **劣势**：依赖大量训练数据，对于资源匮乏的语言支持不足。

3. **基于神经网络的机器翻译（2010s-present）**：
   - **特点**：使用深度神经网络模型，如LSTM和Transformer，自动学习复杂的映射关系。
   - **优势**：翻译质量、速度和适应性显著提高，成为主流方法。

4. **未来发展趋势**：
   - **方向**：更加智能化和个性化，结合上下文理解、情感分析等技术，提高翻译准确性和自然度。
   - **新领域**：跨语言信息检索、多模态翻译等。

### 三、数据集划分

1. **训练集（Training Set）**：
   - **作用**：用于训练模型，使模型学习输入数据与输出结果之间的映射关系。
   - **目标**：让模型在训练数据上尽可能拟合好，学习数据的内在规律。

2. **开发集/验证集（Development/Validation Set）**：
   - **作用**：用于调整超参数、选择模型架构以及防止过拟合。
   - **目标**：通过开发集上的性能评估，选择最佳模型配置，确保模型的泛化能力。

3. **测试集（Test Set）**：
   - **作用**：用于最终评估模型的性能，是衡量模型实际应用效果的标准。
   - **目标**：提供公正、无偏见的性能估计，反映模型在未知数据上的泛化能力。

### 四、赛题解析

1. **赛事背景**：
   - 神经机器翻译技术已取得很大突破，但在特定领域或行业中术语一致性问题仍存在。
   - 通过术语词典纠正翻译结果，可以提高翻译质量。

2. **赛事任务**：
   - 基于术语词典干预的机器翻译挑战赛。
   - 英文为源语言，中文为目标语言。
   - 提供的双语数据和术语词典用于模型训练和测试。

3. **赛题数据**：
   - 训练集：中英14万余双语句对。
   - 开发集：英中1000双语句对。
   - 测试集：英中1000双语句对。
   - 术语词典：英中2226条。

4. **评估指标**：
   - 使用自动评价指标BLEU-4进行评估。
   - BLEU评分用于衡量计算机生成的翻译与参考译文之间的相似度，特别关注n-grams的精确匹配。
   - BLEU-4指的是考虑四元组（连续四个词）的匹配情况。

### 五、baseline优化与思考

1. **初步验证**：选择较小的N值和适中的N_EPOCHS进行快速验证，确保模型和代码的正确性。

2. **逐步优化**：根据初步验证结果，逐步增大N值，观察模型在验证集上的表现，适时调整N_EPOCHS，寻找最佳组合。

3. **最终训练**：在确定最佳参数组合后，使用较大的N值和合适的N_EPOCHS进行最终训练，以获得性能最优的模型。
